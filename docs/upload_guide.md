# GitHub 저장소 사용 안내

저장소 이름: `netflix-user-behavior-analysis`

프로젝트 하나당 저장소 하나를 사용합니다. 첫 화면 README에서 목적·기여·결과를 보고, 코드와 보고서는 각 폴더로 들어가 확인하는 구조입니다.

- Notion의 GitHub 섹션에는 저장소 주소 하나를 연결하세요.
- 기술보고서는 `reports/technical_report.md`에 있습니다. 원본 발표 슬라이드는 제외하고 주요 이미지만 활용했습니다.
- 다음에 파일을 추가할 때는 해당 폴더를 연 뒤 Add file → Upload files를 사용하면 됩니다.
- 공개 저장소에는 원본 데이터, 로컬 계정 정보, `.env`, 임시 복구 파일을 추가하지 마세요.
- 실제 레코드는 데이터 재배포 조건을 확인한 뒤 추가 여부를 결정하세요.
- 저장소에 들어 있는 기존 분석 설명 PDF와 노트북 저장 결과는 원본 분석 자료입니다. 새 요약의 해석 범위와 차이가 있으면 기술보고서의 평가 조건을 기준으로 읽으세요.
